# Changelog

## 2.5.0

- Sorts the merchant's Buy and Sell tabs with the same category rules as the
  player inventory.
- Keeps the selected item and its actions aligned with the visible order in
  the player inventory.
- Preserves item quantities and trade prices while sorting.
- Uses `G1R_InventorySort` as the mod folder name.

## 2.1.0

- Adds separate magic categories for summoning, status effects, and
  transformations.

## 2.0.0

- Adds sorting for all supported inventory categories. The mixed All Items tab
  stays in its original order.
